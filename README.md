ПРОЕКТ «ПОМОГУ — СЮНИК»
========================================

ЦЕЛЬ ПРОЕКТА
-------------
Создать локальный сервис для Сюника, который помогает людям
найти человека, который может выполнить нужную работу или услугу.

Примеры:
- перевозка;
- ремонт;
- доставка;
- уборка;
- покос травы;
- работа на один день;
- помощь по дому;
- аренда;
- другие услуги.

ГЛАВНАЯ ИДЕЯ
-------------
Пользователь пишет:
«Мне нужно ...»

Другой пользователь отвечает:
«Я могу это сделать».

После выполнения заказа платформа получает комиссию.

БИЗНЕС-МОДЕЛЬ
-------------
Регистрация — бесплатно.
Создание заказа — бесплатно.

Планируемая комиссия платформы:
5% с успешно выполненной сделки.

Пример:
Заказ = 20 000 драм.
Комиссия 5% = 1 000 драм.
